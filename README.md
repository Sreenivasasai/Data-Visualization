# Data-Visualization
This project demonstrates the fundamentals of **Data Visualization using Python**.
It includes different types of visualizations created with **Matplotlib**, **Seaborn**, and **NumPy** to analyze and understand data trends, patterns, and relationships.

The notebook contains multiple examples such as:

* Line Charts
* Scatter Plots
* Random Data Visualization
* Sales Analysis Graphs
* GDP Trend Visualization
* Temperature vs Sales Analysis

---

## Technologies Used

* Python
* NumPy

* Matplotlib

* Jupyter Notebook
